# SkillNest

### Free Tools for Students & Career Builders

SkillNest is a free web-based toolkit designed to help students and job seekers manage academic tasks, prepare for careers, and improve everyday productivity.

**Live Website:** https://skillnest-tools.netlify.app/

**GitHub Repository:** https://github.com/Mursaleen-Razzaq/SkillNest

## Features

### Student Tools
- GPA Calculator
- CGPA Calculator
- Percentage Calculator
- Marks Calculator
- Study Planner
- Exam Countdown

### Career Tools
- Resume Builder
- Cover Letter Generator
- Interview Practice
- Job Application Tracker
- Professional Email Generator

### Productivity Tools
- Pomodoro Timer
- Word Counter
- To-Do List
- Flashcards

### Learning Resources
- Internship Guide
- Interview Guide
- Resume Writing Guide
- Study Tips

## Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/Mursaleen-Razzaq/SkillNest.git
```

### 2. Open the Project

Open the SkillNest folder in Visual Studio Code.

### 3. Run the Website

Open the terminal inside the project folder and run:

```bash
npx serve .
```

Open the following address in your browser:

```text
http://localhost:3000
```

You can also open `index.html` directly in your browser or use the VS Code Live Server extension.
