\# SkillNest



\### Free Tools for Students \& Career Builders



SkillNest is a web-based toolkit designed to help students and job seekers manage academic tasks, career preparation, and everyday productivity.



\## Features



\### Student Tools

\- GPA Calculator

\- CGPA Calculator

\- Percentage Calculator

\- Marks Calculator

\- Study Planner

\- Exam Countdown



\### Career Tools

\- Resume Builder

\- Cover Letter Generator

\- Interview Practice

\- Job Application Tracker

\- Professional Email Generator



\### Productivity Tools

\- Pomodoro Timer

\- Word Counter

\- To-Do List

\- Flashcards



\### Learning Resources

\- Internship Guide

\- Interview Guide

\- Resume Writing Guide

\- Study Tips



\## Technologies Used

\- HTML5

\- CSS3

\- JavaScript

\- SVG Icons

\## Run Locally



1\. Clone the repository:



&#x20;  `git clone https://github.com/Mursaleen-Razzaq/SkillNest.git`



2\. Open the SkillNest folder in VS Code.

3\. Open `index.html` in your browser, or use the VS Code Live Server extension.
